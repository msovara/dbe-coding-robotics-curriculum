## Download Instructions

### Option 1: Clone Entire Repository
```bash
git clone https://github.com/ChpcTraining/dsi_coding_school.git
cd dsi_coding_school
```

### Option 2: Download Specific Modules
1. Navigate to module link
2. Click "Code" → "Download ZIP"
3. Extract specific module

### Option 3: Access Online
- Browse directly on GitHub
- View files online
- Download individual files
