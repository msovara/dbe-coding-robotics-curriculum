# Day 1 Scratch solution projects

## How to run `03-interactive-story.sb3`

1. Scratch → **File → Load from your computer** → `03-interactive-story.sb3`.
2. Click the **green flag**.
3. **Click** the Child (Avery).
4. Press the **right arrow** (Road; Friend appears).
5. Press the **right arrow** again (School; ending line).

**Download:** https://github.com/msovara/dbe-coding-robotics-curriculum/raw/main/day-01-scratch/scratch-projects/solutions/03-interactive-story.sb3
