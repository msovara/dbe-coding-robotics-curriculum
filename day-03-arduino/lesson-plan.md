# Day 3: Coding & Robotics with Arduino
## Detailed Lesson Plan

**Duration:** 6-8 hours (Full Day)
**Target Audience:** DBE Teachers (Mixed Experience Levels)
**Prerequisites:** Days 1-2 completion (Scratch and Arduino/S4A basics)
**CHPC Integration:** See [CHPC Robotics Module](https://github.com/ChpcTraining/dsi_coding_school/tree/main/robotics)

**Learning Objectives:**
- Extend Arduino coding and robotics skills from Day 2
- Build more complex physical computing projects
- Apply coding concepts to robotics challenges
- Design and implement Arduino-based solutions

---

## Morning Session (09:00 - 13:00)

### Session 1: Review and Extended Arduino Concepts (09:00 - 10:15)
- Review Day 2: S4A, sensors, actuators
- Recap digital/analog I/O and control structures
- Introduction to more complex program flow
- Planning a robotics/coding project

### 10:30 - 11:00 **Morning Tea Break**

### Session 2: Arduino Coding Projects (11:00 - 12:30)
- Multi-sensor projects
- Using variables and logic for decision-making
- Loops and timing for sequences
- Hands-on: Build an Arduino coding project

### Session 3: Robotics Applications (12:30 - 13:00)
- From coding to robotics: controlling motors and servos
- Simple robotic behaviours (e.g. follow light, react to distance)
- Discussion: Classroom robotics with Arduino

---

## Lunch Break (13:00 - 14:00)

## Afternoon Session (14:00 - 17:00)

### Session 4: Project Development (14:00 - 15:30)
- Design and build a Coding & Robotics project with Arduino
- Integrate sensors, actuators, and code

### 15:30 - 16:00 **Afternoon Tea Break**

### Session 5: Share and Reflect (16:00 - 16:45)
- Short project showcases
- What works in the classroom
- Daily reflection and Q&A

- Preview Day 4: Micro:bit Part 1
